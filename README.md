# Shubham Lokare - React Portfolio

## Modern AI Engineer & Data Scientist Portfolio

### Features
- **Advanced Animations**: Framer Motion, React Spring
- **3D Effects**: Interactive cards, hover animations
- **Modern UI**: Glassmorphism, gradients, particles
- **Responsive Design**: Mobile-first approach
- **Interactive Components**: Skills navigation, project showcase
- **Custom Cursor**: Dynamic cursor effects
- **Loading Animation**: Professional loader
- **Resume Modal**: Full resume view with download

### Technologies Used
- React 18
- Framer Motion
- React Spring
- React Intersection Observer
- React Typed
- Styled Components

### Installation & Setup

1. Install Node.js from https://nodejs.org/
2. Open terminal in project directory
3. Run: `npm install`
4. Run: `npm start`
5. Open http://localhost:3000

### Project Structure
